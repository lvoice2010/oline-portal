# Клиентский портал O'LINE

Прототип клиентского портала контакт-центра O'LINE. Построен на Next.js 14 (App Router) + TypeScript + Tailwind CSS.

## Что внутри

Портал содержит:

- **Дашборд** — обзор подключённых услуг
- **6 типов услуг** со своими отчётами, аналитикой и журналами:
  - Горячая Линия Панго Карс (поминутная тарификация)
  - Горячая Линия Адамас (FTE-команда)
  - Нейроассистент на входящую линию (AI, post-pay)
  - Исходящая кампания Q2 2026 (проектная)
  - Контроль качества (в разработке)
  - Ежеквартальный ИИ-отчёт
- **Витрина услуг** с рекомендациями и каталогом
- **Архив отчётов** и **Финансовые документы**
- **Демо-модалки** с примерами отчётов и тестовым звонком ассистенту

Подробное описание каждой страницы — в [PRESENTATION.md](./PRESENTATION.md) или `.docx`.

## Стек

- **Next.js 14** (App Router)
- **TypeScript** strict mode
- **Tailwind CSS** с кастомной палитрой O'LINE (navy + sage)
- **Recharts** для графиков
- **Lucide React** для иконок

## Локальный запуск

```bash
npm install
npm run dev
# Открой http://localhost:3000
```

## Сборка для продакшена

```bash
npm run build
npm run start
```

## Деплой на Vercel

Проект готов к деплою на Vercel из коробки. Никаких переменных окружения не требуется — все данные в моках.

1. Импортируй репозиторий на [vercel.com/new](https://vercel.com/new)
2. Framework Preset: **Next.js** (определится автоматически)
3. Build Command: `npm run build` (по умолчанию)
4. Нажми **Deploy**

Деплой пройдёт за ~2 минуты.

## Структура проекта

```
src/
├── app/                    # Next.js App Router
│   ├── dashboard/          # Главная
│   ├── services/[id]/      # Карточка услуги
│   ├── catalog/            # Витрина услуг
│   ├── documents/          # Финансовые документы
│   ├── reports-archive/    # Архив отчётов
│   └── messages/           # Отправить сообщение
├── components/             # Компоненты
│   ├── layout/             # Sidebar, Topbar
│   ├── ui/                 # Базовые UI-элементы
│   ├── outbound-*.tsx      # Спец-табы для исхода
│   ├── service-*.tsx       # Универсальные табы
│   └── *-modal.tsx         # Модалки
└── lib/
    ├── mock-data.ts        # ~5 000 строк моков
    └── utils.ts            # Утилиты (cn)
```

## Ключевые принципы дизайна

1. **Не показываем недогруз пакета** — клиент не должен задуматься «зачем мне такой большой пакет»
2. **Все формулировки — для клиента, не для менеджера** — никаких ASA/AHT/AR
3. **Не критикуем нашу работу** — все инсайты про рынок и возможности клиента
4. **Кросс-сейл в каждом блоке** — рекомендации новых услуг встроены нативно
5. **Один источник правды** — каждое число живёт в одном месте
